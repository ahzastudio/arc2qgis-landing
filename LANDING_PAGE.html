Fitur Lengkap ARC2QGIS

📁

Import ArcGIS Project

Konversi file MXD (ArcMap) dan APRX (ArcGIS Pro) lengkap dengan semua layer, symbology, dan layout.

🎯

Convert Layer File

Konversi file LYR dan LYRX dengan symbology utuh. Support Simple, Categorized, dan Graduated renderer.

🎨

Import ArcGIS Style

Import file STYLX (ArcGIS Pro Style) ke QGIS. Semua simbol point, line, polygon, dan text otomatis terkonversi.

🗺️

Layout Conversion

Layout peta dari ArcGIS otomatis terkonversi ke QGIS Print Layout dengan extent dan scale yang benar.

💾

Auto-Save QML

Style otomatis disimpan sebagai file QML yang bisa digunakan ulang kapan saja.

🇮🇩

Interface Bahasa Indonesia

Semua pesan dan log dalam Bahasa Indonesia yang mudah dipahami.

Apakah ada trial gratis?

Ya! Anda bisa mencoba plugin ini gratis selama 180 hari (6 bulan). Cukup install plugin, dan trial otomatis aktif. Tidak perlu kartu kredit atau registrasi.

Bagaimana cara pembayaran?

Kami menerima transfer bank (BCA, Mandiri, BNI, BRI), e-wallet (GoPay, OVO, Dana), dan marketplace (Tokopedia, Shopee). Untuk corporate bisa via invoice.

Apakah lisensi berlaku selamanya?

Ya! Ini adalah perpetual license (sekali bayar, pakai selamanya). Bukan subscription bulanan/tahunan. Update gratis untuk 1 tahun pertama (Individual) atau selamanya (Commercial/Corporate).

Apakah bisa digunakan di beberapa komputer?

Tergantung paket: Individual (1 komputer), Commercial (3 komputer), Corporate (10 komputer). Lisensi terikat dengan Hardware ID komputer.

Apakah support file ArcGIS versi lama?

Ya! Plugin ini support ArcMap 10.x (MXD, LYR) dan ArcGIS Pro (APRX, LYRX, STYLX). Selama Anda punya ArcGIS Python terinstall, plugin bisa konversi file-nya.

Bagaimana jika saya ganti komputer?

Hubungi kami via email dengan menyertakan license key lama dan Hardware ID komputer baru. Kami akan generate license key baru gratis (1x per tahun).

Apakah ada garansi uang kembali?

Ya! Jika dalam 30 hari pertama Anda tidak puas, kami akan refund 100% tanpa pertanyaan. Kami yakin plugin ini akan sangat membantu pekerjaan Anda.
